## 🚀 How to Publish to GitHub Pages (2 Minutes)

### Option 1: As your Main GitHub Profile Website (`Janardhan-Jillela.github.io`)
This gives you the cleanest, most prestigious URL: `https://janardhan-jillela.github.io/`

1. Open your terminal in this directory:
   ```bash
   cd "C:\Users\JANARDHAM\.gemini\antigravity\scratch\janardhan-portfolio"
   ```
2. Initialize git and commit:
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit for Janardhan AI portfolio"
   ```
3. Create a repository on GitHub named:
   `Janardhan-Jillela.github.io`
4. Link and push:
   ```bash
   git branch -M main
   git remote add origin https://github.com/Janardhan-Jillela/Janardhan-Jillela.github.io.git
   git push -u origin main
   ```
5. Your portfolio will be live at:  
   👉 **`https://janardhan-jillela.github.io`**

---

### Option 2: As a Project Repository (`portfolio`)
If you prefer a repository named `portfolio`:

1. Create a repository on GitHub named `portfolio`.
2. Push your code:
   ```bash
   git remote add origin https://github.com/Janardhan-Jillela/portfolio.git
   git push -u origin main
   ```
3. On GitHub, navigate to **Settings > Pages**.
4. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
5. Your portfolio will be live at:  
   👉 **`https://janardhan-jillela.github.io/portfolio`**
